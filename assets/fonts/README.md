# Report fonts

Noto Sans Regular and Bold are bundled for offline PDF generation under the SIL Open Font License in `OFL.txt`.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans (downloaded October 9, 2026). These static fonts cover Latin, Greek, and Cyrillic text, not every script or emoji. The PDF renderer rejects unsupported characters instead of silently substituting missing glyphs. The journal and CSV retain original text.
