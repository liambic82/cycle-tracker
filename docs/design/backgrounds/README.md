# Built-in background candidates — October 9, 2026

**Status: images generated for owner review; not yet bundled into the app.** The owner liked the initial appearance proposals and requested six additional colors, with two feminine, soft, pretty images per named palette. These twelve candidates are additions to the original Plum, Sage, and Ocean choices.

The artwork was generated with the built-in `image_gen` tool. Exact prompts, names, and identifiers are in [prompts.json](prompts.json). The PNG masters below are saved unchanged from generation. Images are intended to be available offline once approved and included in the app; they introduce no image-hosting requirement.

## Design and implementation notes

- Each palette pairs two distinct compositions within a soft painted style. The images have subdued central areas and stronger detail toward the edges, leaving room for opaque journal surfaces.
- The owner is reviewing the images themselves. Palette names, both options in each pair, and any requested revisions should be recorded before bundling them. There is no requirement to select only one image per palette.
- These are square masters. Phone and desktop cropping, image visibility, dark-mode treatment, readable controls, and compressed asset size still need app-level validation. Landscape images may need a different crop position from the botanical images.
- Keep text and records on opaque surfaces and keep flow/spotting/no-flow/unlogged meanings independent of the decorative palette. Built-in artwork does not replace Plain, Soft wash, or the proposed personal-image option.
- Preserve the original masters; create optimized app derivatives only after review. No app source, version number, APK, health records, image picker, or runtime theme behavior changed in this image-review step.
- Visual inspection confirmed all twelve outputs are present, fit their requested color families, contain no interface or lettering, and provide two visually distinct options per palette. Image dimensions and integrity are recorded in [assets.json](assets.json). This does not claim native-device or accessibility validation.
